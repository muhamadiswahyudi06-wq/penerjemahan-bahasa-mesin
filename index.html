Penerjemah Bahasa Mesin

Ubah teks biasa menjadi kode ASCII dan biner yang dipahami komputer, atau terjemahkan biner kembali menjadi teks.

Pita berlubang
Setiap kolom satu karakter. Lubang gelap berarti bit 1, lubang terang berarti bit 0. Bit paling atas adalah bit terbesar.

Aplikasi versi Windows

Unduh penerjemah ini sebagai aplikasi .exe untuk dijalankan di komputer Windows tanpa browser.

Unduh penerjemah_bahasa_mesin.exe
Karakter di luar ASCII (misalnya huruf beraksen atau emoji) ditulis sebagai beberapa byte UTF-8.
